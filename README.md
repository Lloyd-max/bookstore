# Dog-Ear Books (React & Tailwind Version)

An independent bookstore single-page application rebuilt with **React**, **Vite**, and **Tailwind CSS**, evolving from Assignment 1's vanilla HTML and CSS implementation.

## Tech Stack
- **React (Vite)** for component architecture and state management.
- **Tailwind CSS** for utility-first responsive styling.
- **Plain JavaScript** for data structures and event handling.

## What's on the page
- **Sticky Header & Navigation:** Quick scroll links to sections.
- **Hero Section:** Intro to the bookstore.
- **Curated Catalog with useState Filter:** Dynamic filtering across Fiction, Nonfiction, and Staff Picks.
- **Reusable Controlled Component (`ReserveCounter`):** Interactive copy-reservation counter per book card using local state.
- **Events Section:** Upcoming readings and book club dates.
- **Footer:** Opening hours, contact details, and location.
